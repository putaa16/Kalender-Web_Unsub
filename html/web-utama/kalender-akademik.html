Berlangganan Kalender

Tambahkan kalender akademik langsung ke Google Calendar Anda

Info Admin: Masukkan API Key dan Calendar ID Anda di bawah ini. Konfigurasi ini disimpan di browser Anda (localStorage) untuk pengetesan. Agar permanen bagi semua pengunjung, ubah langsung variabel di kode HTML.

Cara Mendapatkan Kredensial:

  • Google Calendar ID: Buka Google Calendar > Klik opsi (ikon 3 titik) di sebelah nama Kalender Anda > Setelan dan Berbagi > Centang "Sediakan untuk umum" agar dapat diakses website > Gulir ke bawah ke bagian "Integrasikan Kalender" lalu salin ID Kalender (formatnya seperti email atau diakhiri @group.calendar.google.com).
  • Google API Key: Buka Google Cloud Console > Buat proyek baru/pilih proyek > Buka APIs & Services > Library > Cari dan aktifkan Google Calendar API > Buka menu Credentials > Klik + Create Credentials > Pilih API Key.
